# GAGO Furniture — React prototype

A frontend-first React/Vite prototype based on the supplied GAGO brand story and visual references.

## Run
```bash
npm install
npm run dev
```
Then open the local Vite URL.

## Included flows
- Cinematic onboarding / Port Said story
- Home with From Land to Sea hero
- Categories and product listing
- Shell-inspired product cards
- Product detail
- Cart + quantity controls
- Checkout + payment selection
- Order confirmation
- GAGO story / Port Said timeline
- Distributor locations
- Search
- Profile / account menu

## Notes
This is a high-fidelity frontend prototype. Product, stock, customer, payment and distributor data are local demo data and should be replaced by an API/backend before production.
